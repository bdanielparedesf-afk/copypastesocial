# Content Copier

**Importa. Selecciona. Publica.**

Importa contenido de redes sociales (Instagram, YouTube, Facebook, TikTok), elige exactamente lo que quieres copiar y publícalo en tus destinos sin perder el control.

## Stack

Next.js 15, Supabase, Framer Motion, Design #0A0A0B

## Rutas

21 rutas API + cron

## Cron

03:05 UTC = 00:05 Santiago

## Quota YT

6 videos/día → retrying automático

## Upload local

1000 videos sin storage, directo a jobs

## Getting Started

```bash
npm install
cp .env.example .env
npm run dev
```
